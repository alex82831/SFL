# 02 — FizzBuzz

Control flow: `if/elsif/else` as an *expression* (it produces a value, so it
can sit inside a `println` or a lambda), `for` over `range`, and
`while`/`break`/`continue`.

Note the test imports `../src/main` — importing a module runs its top level
once and its `def`s become visible, which is all a test needs.

## Run

```bash
sfl build run
sfl build test
```
