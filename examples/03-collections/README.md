# 03 — Collections

Arrays, objects and tuples, worked over with the higher-order builtins:
`map`/`filter`/`reduce`, `groupBy`/`frequencies`, `sortBy`/`maxBy`,
`flatMap`/`unique`/`zip`, `chunk`/`windows` — plus destructuring
(`val [a, ...rest] = ...`, `val {name} = ...`, tuples) and copy-on-write
updates (`assoc`, `assocIn`, `updateIn`, `getIn`) for when you want edited
copies instead of mutation.

## Run

```bash
sfl build run
sfl build test
```
